# my profil

تطبيق شبكة اجتماعية حديث للهواتف والأجهزة اللوحية مبني بلغة **Kotlin** و**Jetpack Compose (Material Design 3)** مع دعم كامل للغة العربية (**RTL**) والإنجليزية (**LTR**) وقابلية التوسع لإضافة لغات أخرى، وقاعدة بيانات سحابية مؤمّنة عبر **Cloud Firestore** و**Google Sign-In (Credential Manager)**.

---

## المزايا المنفذة
- **المصادقة والملف الشخصي**:
  - تسجيل الدخول بحساب Google عبر Jetpack Credential Manager وتسجيل الخروج النظيف.
  - صفحة ملف شخصي تعرض الصورة، الاسم الظاهر، اسم المستخدم (`@handle`)، النبذة، وإحصاءات المنشورات والمتابعين والمتابَعين، مع إمكانية التعديل.
- **الخلاصة الزمنية والمنشورات**:
  - عرض المنشورات بترتيب زمني مع تصفية ("كل المنشورات" / "المتابَعون").
  - إنشاء منشور نصي مع صورة اختيارية عبر **Android Photo Picker** (بدون أذونات تخزين، يدعم JPEG/PNG/WebP مع التحقق من الحجم وضغط الصورة بأمان).
  - تعديل المنشورات وحذفها مع تأكيد الحذف.
  - الإعجاب وإزالة الإعجاب، وإضافة وحذف التعليقات عبر عمليات Batch ذرية في Firestore.
- **التفاعل الاجتماعي والاستكشاف والإشعارات**:
  - متابعة وإلغاء متابعة المستخدمين، وعرض قوائم المتابعين والمتابَعين.
  - البحث الفوري عن الأشخاص والمنشورات.
  - إشعارات فورية داخل التطبيق عند الإعجاب أو التعليق أو المتابعة مع إمكانية التحديد كمقروء.
- **الخصوصية والأمان والوصول**:
  - خيار جعل الملف الشخصي خاصًا (`isPrivate`) ومنع ظهوره في نتائج البحث العام.
  - حظر وإلغاء حظر المستخدمين وإدارة القائمة من الإعدادات.
  - الإبلاغ عن المحتوى أو الحسابات المسيئة (`reports`).
  - وضع داكن (حسب النظام / فاتح / داكن)، وتكبير الخط، والتباين المرتفع، وحفظ الإعدادات محليًا عبر DataStore ومزامنتها في المسار الخاص للمستخدم.
- **دعم اللغات والبيانات التجريبية**:
  - فصل النصوص بالكامل في `res/values/strings.xml` و`res/values-ar/strings.xml` مع تبديل الاتجاه (`RTL` / `LTR`) وتنسيق التواريخ والأرقام محليًا.
  - بيانات تجريبية مميزة بوضوح بشارة **"تجريبي / Sample"** يمكن إظهارها أو إخفاؤها من الإعدادات.

## ملاحظات حول الإعداد السحابي والميزات الاختيارية في Firebase Console
- تم إعداد **Cloud Firestore** و**Google Sign-In** تلقائيًا مع قواعد أمان صارمة (`firestore.rules`).
- الميزات التالية تتطلب تفعيلًا يدويًا في **Firebase Console** إذا رغبت بإضافتها لاحقًا:
  1. **تسجيل الدخول بالبريد الإلكتروني وكلمة المرور واستعادة كلمة المرور** (تفعيل مزود Email/Password في Authentication).
  2. **رفع ملفات وسائط كبيرة عبر Cloud Storage** (حاليًا تُضغط الصور اختياريًا بأمان وتُحفظ كبيانات مصغرة محدودة الحجم).
  3. **إشعارات الدفع الخارجية (FCM Push Notifications)** (حاليًا تتوفر إشعارات فورية داخل التطبيق عبر Firestore).

## تعليمات التشغيل والاختبار والنشر

### 1. التشغيل المحلي (Build & Run)
- افتح المشروع في Android Studio أو شغّل البناء عبر Gradle:
  ```bash
  gradle :app:assembleDebug
  ```
- تأكد من تفعيل **Google Sign-In** وربط بصمات `SHA-1` / `SHA-256` في `app/google-services.json` عند الاختبار على جهاز فعلي أو محاكي مزود بخدمات Google Play.

### 2. اختبار قواعد الأمان والمنطق (Testing)
- **اختبار قواعد Firestore عبر JavaScript (محاكي محلي):**
  ```bash
  firebase emulators:start --only firestore,auth --project demo-no-project
  FIRESTORE_EMULATOR_HOST="127.0.0.1:8085" node --test firestore.test.js
  ```
- **اختبار مستودع البيانات في Android (Robolectric + Emulators):**
  ```bash
  gradle :app:testDebugUnitTest --tests '*Rule*'
  ```
- **تشغيل اختبارات الوحدة العامة:**
  ```bash
  gradle :app:testDebugUnitTest
  ```

### 3. نشر قواعد الأمان وبناء نسخة الإصدار (Deploy & Release)
- لنشر قواعد أمان Firestore إلى مشروعك:
  ```bash
  firebase deploy --only firestore:rules
  ```
- لبناء حزمة النشر لمتجر Google Play (`.aab`) بعد ضبط مفاتيح التوقيع (`KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD`):
  ```bash
  gradle :app:bundleRelease
  ```
